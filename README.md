# AnimalWatch

Android application for reporting and discovering animals using location-based data, interactive maps, and user-submitted images.

## Getting Started

### Requirements

* Android Studio
* JDK 11+
* Android SDK
* Firebase project
* Google Maps API key
* Cloudinary account

### Setup

1. Clone the repository:

```bash
git clone https://github.com/veljkotosic/AnimalWatch.git
```

2. Open the project in Android Studio.

3. Configure Firebase by adding your `google-services.json` file to:

```text
app/google-services.json
```

4. Configure your Google Maps API key.

5. Configure your Cloudinary credentials.

6. Sync the project with Gradle and run the application on an Android device or emulator.

## Tech Stack

* Kotlin
* Jetpack Compose
* Firebase
* FireStore
* Google Maps
* GeoFire
* Cloudinary
